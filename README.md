## Descripción del Proyecto
Proyecto web desarrollado con Django y Bootstrap correspondiente a la Evaluación Sumativa 2. 
El sitio web contiene un catálogo de películas dividido en dos categorías:
- Acción (10 películas)
- Ciencia Ficción (10 películas)

Cada película incluye su nombre, año, descripción e imagen representativa.
